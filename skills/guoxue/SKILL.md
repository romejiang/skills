# 果学选股方法论

"果学"是一套"以果推因"的选股体系：先确定一定会产生十倍股的条件，再反推锁定目标股票。

## 核心公式

> **世界级情绪 + 行业地位 = 十倍股**

## 工作流程

### 1. 识别"世界级情绪"

查找并验证当前是否存在符合条件的情绪：

| 维度 | 判定标准 |
|------|----------|
| 规模 | 全球性，能引发中美资本共振 |
| 持续性 | 超过一年，不是几天的题材炒作 |
| 对标锚点 | 有成熟商业落地案例（如SpaceX、英伟达、特斯拉） |
| 政策背书 | 国家队入局或政策资金明确流向 |
| 大佬站台 | 马斯克、软银等顶级资本真金白银投入 |

**情绪来源**：
- 大佬言行（马斯克、硅谷大佬）
- 国家政策（十五五规划、超长期国债投向）
- 产业革命（AI、无人驾驶、机器人）
- 跨市场映射（美股/港股对标锚点）

### 2. 确定"行业地位"

在情绪对应的赛道中找到细分龙头：

| 标准 | 说明 |
|------|------|
| 不可替代性 | 离开它产业链转不动 |
| 订单锁定 | 已有确定订单，非画饼 |
| 技术壁垒 | 竞争对手短期无法复制 |
| 产能优势 | 全球只有它能大规模供货 |
| 大客户绑定 | 华为/比亚迪/特斯拉供应商 |

**找龙头步骤**：
1. 确定情绪对应的大赛道
2. 细分到具体环节
3. 找出该细分领域的龙头公司

### 3. 估值判断

**概率估值法**：`估值 = 行业天花板 × 成功概率`

示例：SpaceX估值10万亿 × 10%成功概率 = 1万亿市值空间

### 4. 买卖点判断

| 时机 | 信号 | 操作 |
|------|------|------|
| 买入 | 大佬兴奋 + 精英嘲讽 + 股价低位 | 潜伏建仓 |
| 持有 | 情绪持续发酵，行业地位未变 | 低吸高抛做波段 |
| 卖出 | 龙头两个跌停/高位横盘1-2月/新板块抢地位 | 离场观望 |

### 5. 操作策略

**散户推荐**：鑫多多模式（涨价+细分龙头）
- 2-3个月潜伏周期
- 不需要天天盯盘
- 围绕龙头低吸高抛
- 慢即是快

**核心口诀**：有妖抓妖，没妖做龙头，没龙头做套利

## 关键心法

- **跳出股市看股市**：十倍股秘密在社会财经，不在K线图
- **跟大佬，反精英**：马斯克跟天走，精英反着干
- **吃鱼身，不吃鱼尾**：赚中间最肥美部分
- **市场永远是对的**：顺势而为，不与市场争论
