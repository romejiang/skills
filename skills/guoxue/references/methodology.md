## 一、情绪体系

### 1.1 什么是"情绪"

果学所说的"情绪"**并非股市中的短期投机情绪**，而是：

| 层面 | 定义 |
|------|------|
| 社会财经情绪 | 超越股市本身，存在于社会财经层面的宏大叙事 |
| 世界级规模 | 全球性，能引发中美甚至全球共振 |
| 持续时间 | 必须持续超过一年，不是几天几周的热点 |
| 非理性力量 | 股市上涨的真正核心动力，不是基本面 |

**核心认知**：
- 股市从来不是理性的，上涨的真正核心动力是情绪
- 真正的"主力"不在K线图里，而在社会财经中
- 马斯克说一句话、发一个表情包，就能形成全球共振的社会情绪

### 1.2 情绪的四大来源

| 来源 | 具体方法 | 案例 |
|------|----------|------|
| **大佬言行** | 追踪马斯克、硅谷大佬的公开发言与动作 | SpaceX估值、特斯拉机器人Optimus、太空光伏 |
| **国家政策** | 关注国家战略方向 | 新基建、商业航天、可控核聚变、十五五规划 |
| **产业革命** | "从0到1"的科技变革 | AI4S、智能驾驶、太空光伏、机器人 |
| **跨市场映射** | 美股/港股的对标锚点 | SpaceX 1.5万亿美元估值 → A股商业航天 |

### 1.3 情绪判定标准

| 维度 | 判定方法 |
|------|----------|
| 规模 | 必须是"世界级"，能引发全球资本共振 |
| 持续性 | 持续时间超过一年，不是几天的题材炒作 |
| 对标锚点 | 有成熟的商业落地案例作为估值参照 |
| 政策背书 | 国家队入局、政策资金明确流向 |
| 大佬站台 | 马斯克、软银等顶级资本的真金白银投入 |

### 1.4 真风口 vs 伪风口

| 类型 | 特征 | 案例 |
|------|------|------|
| **真风口** | 有成熟对标锚点 | 芯片（英伟达）、新能源车（特斯拉）、商业航天（SpaceX） |
| **伪风口** | 缺乏成熟商业闭环 | 某些低空经济、深海探测概念 |

### 1.5 情绪周期信号

| 阶段 | 信号 | 市场表现 |
|------|------|----------|
| 萌芽期 | 大佬异常兴奋，精英疯狂嘲讽 | 股价低位震荡 |
| 发酵期 | 政策密集出台，资金涌入 | 主升浪启动 |
| 高潮期 | 路边阿姨都在谈论 | 估值透支 |
| 退潮期 | 龙头连续跌停，新板块抢地位 | 深度调整 |

## 二、地位体系

### 2.1 什么是"地位"

| 定义 | 说明 |
|------|------|
| 行业细分龙头 | 某个细分领域的绝对领袖，具有不可替代性 |
| 卡脖子地位 | 卡住整个产业链某环节的咽喉 |
| 非涨幅最高 | 真正的龙头不等于涨得最好的股票 |
| 长期领先 | 拉长周期看，能跑赢通胀、跑赢频繁交易者 |

**关键区分**：
- **投机龙头**：涨幅最大，风险极高，需每天4小时盯盘
- **行业细分龙头**：行业地位稳固，适合普通散户

### 2.2 地位的三种识别方法

| 方法 | 具体操作 | 案例 |
|------|----------|------|
| 唯一性 | 找"唯一能接单"的公司 | 当年唯一能造巨轮的造船厂 |
| 技术护城河 | 掌握核心技术，卡住产业链关键环节 | 国产HJT超薄电池、激光雷达 |
| 产能稀缺 | 全球某产能只有该公司有 | 海外大厂火灾后的国内化工龙头 |

### 2.3 地位判断五大标准

| 标准 | 说明 |
|------|------|
| 不可替代性 | 离开它，产业链就转不动 |
| 订单锁定 | 已有确定的订单，不是画饼 |
| 技术壁垒 | 竞争对手短期内无法复制 |
| 产能优势 | 全球只有它能大规模供货 |
| 大客户绑定 | 华为、比亚迪、特斯拉等巨头的供应商 |

### 2.4 找龙头的步骤

1. 确定情绪对应的大赛道（如商业航天、AI4S、无人驾驶）
2. 细分到具体环节（如激光雷达、卫星光伏翅膀、端到端大模型）
3. 找出该细分领域的龙头公司

### 2.5 地位分级

| 级别 | 定义 | 特征 |
|------|------|------|
| 牛股 | 个股有利好 | 单独上涨 |
| 龙头 | 利好够大，带动板块 | 引领板块行情 |
| 妖股 | 代表全市场赚钱效应 | 承载大盘情绪的宣泄口 |

## 三、估值体系

### 3.1 传统估值的失效

| 传统方法 | 问题 |
|----------|------|
| PE（市盈率） | 科技股初期往往亏损，PE无法适用 |
| 涨价涨量 | 很多股票没业绩也在涨 |
| 技术分析 | K线图只是结果，不是原因 |

### 3.2 概率估值法

**核心公式**：`估值 = 行业天花板 × 成功概率`

**操作步骤**：

| 步骤 | 操作 |
|------|------|
| 锚定天花板 | 找到海外对标公司的估值 |
| 计算概率 | 中国成功的可能性 |
| 估值推导 | 天花板 × 概率 = 合理估值 |
| 对比现价 | 判断是否存在空间 |

**案例推演**：

商业航天估值：
- 锚点：SpaceX 1.5万亿美元 ≈ 10万亿人民币
- 10%概率 = 1万亿市值
- 1%概率 = 1000亿市值
- 当前A股相关公司市值几百亿 → 存在巨大空间

### 3.3 涨估值模式

**核心逻辑**：当对标的天花板变了，所有相关公司估值都要重估

| 触发条件 | 市场反应 |
|----------|----------|
| 海外对标公司估值大涨 | A股映射公司估值重估 |
| 成熟商业案例出现 | 整个赛道估值天花板打开 |
| 政策定调 | 行业预期改变 |

### 3.4 跨市场对标

| 指标 | 对标方法 |
|------|----------|
| 市占率 | 细分领域的市场份额排名 |
| 估值对标 | 与港股/美股同类公司估值比较 |
| 流动性溢价 | A股3万亿成交量 > 港股，同样公司应给更高估值 |

## 四、操作体系

### 4.1 买卖点判断

| 时机 | 信号 | 操作 |
|------|------|------|
| **买入** | 大佬兴奋 + 精英嘲讽 + 股价低位 | 潜伏建仓 |
| **持有** | 情绪持续发酵，行业地位未变 | 低吸高抛做波段 |
| **卖出** | 龙头两个跌停/高位横盘1-2月/新板块抢地位 | 离场观望 |

### 4.2 行情见顶信号

1. **龙头信号**：绝对龙头连续两个跌停，或高位横盘震荡一两个月
2. **新老交替**：出现更强的新板块，抢夺市场地位

### 4.3 两类游资模式对比

| 类型 | 陈小群模式 | 鑫多多模式 |
|------|------------|------------|
| 逻辑 | 涨估值（投机龙头） | 涨价（细分龙头） |
| 周期 | 快进快出 | 2-3个月潜伏 |
| 盯盘 | 每天4小时 | 不需要 |
| 风险 | 连续跌停风险 | 下跌空间有限 |
| **适合散户** | ❌ | ✅ |

### 4.4 散户最佳策略

1. **选主线**：锁定"情绪+地位"的主赛道
2. **选龙头**：行业细分龙头（不是涨幅最高的）
3. **低吸高抛**：在龙头上反复做波段
4. **不换股**：除非行业地位变化或新板块抢夺地位
5. **慢即是快**：不追涨杀跌，复利惊人

### 4.5 操作口诀

> **有妖抓妖，没妖做龙头，没龙头做套利**

- 市场流动性充裕时（如3万亿成交量），优先抓妖股
- 妖股不讲个股逻辑，讲的是大盘赚钱效应
- 妖股是大盘情绪的宣泄口

## 五、风险控制

### 5.1 绝对禁区

| 禁忌 | 原因 |
|------|------|
| 高杠杆 | 一次黑天鹅可能清零 |
| 追涨杀跌 | 跑不过量化，必被收割 |
| 迷信信息差 | 现在信息差只有半小时，量化毫秒级响应 |
| 迷信主力 | 股市没有主力，只有市场合力 |

### 5.2 仓位管理

| 原则 | 具体做法 |
|------|----------|
| 逢低加仓 | 看好时重仓买入，不是小仓试水再追高 |
| 严格止损 | 不对劲马上走，不装死变长线股东 |
| 不用杠杆 | 穿越牛熊，享受复利 |

### 5.3 心态管理

| 心法 | 说明 |
|------|------|
| 跟大佬，反精英 | 马斯克跟天走，精英反着干 |
| 市场永远是对的 | 不与市场争论合理性 |
| 吃鱼身不吃鱼尾 | 赚中间最肥美部分，不贪最后一涨 |
| 慢即是快 | 追求复利，不追求暴富 |

### 5.4 大难不死策略

关注那些经历考验后突围的股票：
- 爆量后不跌反涨 = 新资金进场
- 突破监管红线（如8板突破7板红线）= 资金看好后续空间
- 大难不死，必有后福
