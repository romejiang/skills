### 投资分析类

#### guoxue

黄平"果学"选股方法论助手。基于"情绪+地位"的核心公式，帮助识别潜在的十倍股机会。

**核心公式**：

> **世界级情绪 + 行业地位 = 十倍股**

**使用场景**：

- 分析当前市场的"世界级情绪"热点
- 识别特定赛道的"行业细分龙头"
- 判断股票的买入/卖出时机
- 评估某只股票是否符合"情绪+地位"选股标准
- 寻找下一个热点赛道和投资机会
- 学习和应用果学方法论进行投资分析

**触发词**：`果学`、`情绪+地位`、`十倍股`、`选股`、`热点分析`、`龙头股`、`妖股`

**示例**：

```bash
# 分析当前市场热点
请用果学方法分析当前市场有哪些世界级情绪？

# 评估个股
用果学方法评估一下 XXX 股票是否符合选股标准

# 寻找龙头
帮我在人形机器人赛道找一下细分龙头
```
